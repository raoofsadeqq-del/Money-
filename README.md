# My Finance (Android, Kotlin + Compose + Room)
Add to project-level build.gradle.kts the plugins: com.android.application, org.jetbrains.kotlin.android,
com.google.devtools.ksp, org.jetbrains.kotlin.plugin.compose (Kotlin 2.x). Open in Android Studio and sync.
Not yet compiled/tested. Roadmap: quarterly report screen, bill add UI + mark paid + monthly rollover,
search/filter UI (DAO.search ready), CSV export, biometric lock, multi-currency, charts library (Vico).
